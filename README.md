# Abhishek Sharma | Personal Portfolio

This project is my personal portfolio website built with React + TypeScript + Vite. It showcases my professional experience, skills, projects, achievements, and contact details.

Live site: https://abhisheksharma1310.github.io

## About

This portfolio is designed to present my work as a full-stack developer and IoT engineer, highlighting:

- Experience across SaaS, robotics, and IoT platforms
- Technical skill domains in frontend, backend, databases, cloud, and DevOps
- Product and project case studies
- Achievements and professional background
- Social links and contact information

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- pnpm

## Run Locally

**Prerequisites:** Node.js and pnpm

1. Install dependencies:
   `pnpm install`
2. Start the development server:
   `pnpm dev`
3. Open the local app in your browser (usually at http://localhost:5173)

## Build for Production

```bash
pnpm build
```
